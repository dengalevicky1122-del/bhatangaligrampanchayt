# ग्रामपंचायत वेबसाइट (स्थापने संदर्भात)

हा एक हलका, पूर्णपणे मोबाईल-फ्रेंडली स्टेटिक साईट टेम्पलेट आहे — मराठी भाषेत सामग्रीसह — ज्याचा उपयोग आपल्या ग्रामपंचायतीसाठी करता येईल.

फायली:
- `index.html` — मुख्य पान (मराठी)
- `assets/styles.css` — साईट शैली
- `assets/scripts.js` — लहान JavaScript इंटरॅक्शन्स

लोकलपणे चालविणे:
Windows वर PowerShell मध्ये फक्त `index.html` उघडा ब्राउझरमध्ये. उदाहरणार्थ:

```powershell
Start-Process index.html
```

QR/ऑनलाइन पेमेंट एकत्रीकरण:
- सरकारी पेमेंट/UPI QR इमेज वरून `assets/qr.png` म्हणून सेव्ह करा आणि `index.html` मधील QR `img` चा `src` बदलावा.
- अधिक सुरक्षित व्यवहारासाठी पेमेंट गेटवे किंवा बैंकची अधिकृत API वापरा (वेबसर्व्हर आवश्यक).

होस्टिंग पर्याय (किफायतशीर):
- GitHub Pages — सोपे आणि मोफत.
- Netlify किंवा Vercel — जलद वितरण आणि SSL.

पुढे काय करावे (शिफारस):
- डेटा व्यवस्थापनासाठी हलका CMS (Netlify CMS / Google Sheets + simple API) जोडणे.
- PDF/दस्तऐवज अपलोडसाठी `uploads` व व्यवस्थापक पॅनेल.
- अधिकृत QR/Payment integration साठी तांत्रिक माहिती (gateway API keys).

जर आपण हवे असेल तर मी:
- या साईटसाठी GitHub repo तयार करून सर्व फायली पुश करू शकतो.
- GitHub Pages वर एक-क्लिक deploy सेट करू शकतो.
- फॉर्म साठी एक छोटा serverless endpoint (Netlify Functions) तयार करू शकतो.
